## 🇬🇧 English

### 📌 Overview
**BenX PC Cleaner** is a clean, no-nonsense Windows maintenance script crafted by **Benjamin Krishan (BenX Development)**. Unlike fake optimization scripts that only display decorative animations, BenX PC Cleaner actively scans, targets, and removes gigabytes of temporary files, outdated cache, broken dump files, and update residue to restore disk space and improve system responsiveness.

---

### ✨ Features
- 🧹 **User Temp Cleanup:** Wipes residual temporary application files (`%temp%`).
- 🖥️ **System Temp Cleanup:** Deletes system-level temporary files (`C:\Windows\Temp`).
- ⚡ **Prefetch Data Refresh:** Cleans outdated Prefetch files to resolve stale application data.
- 📦 **Windows Update Cache Purge:** Clears old update installer cache (`SoftwareDistribution\Download`) which often occupies gigabytes of storage.
- 🌐 **Flush DNS Resolver Cache:** Fixes network lags, DNS conflicts, and outdated routing records.
- 🛠️ **Crash Dumps & Error Logs:** Removes leftover error logs and crash memory dumps.
- 🗑️ **Recycle Bin Cleanup:** Empties all drive recycle bins in one go.
- 🛡️ **100% Safe:** Skips active/locked files and never removes essential operating system files.

---

### 📥 Download & Usage

1. **Download the Script:**
   - Download the file `BenX-PC-Cleaner.bat` from this repository.
2. **Run as Administrator:**
   - **Right-click** on `BenX-PC-Cleaner.bat` and select **"Run as administrator"**.
   *(Administrative privileges are strictly required to clean system and update folders).*
3. **Finish:**
   - Let the cleanup process complete.
   - Once completed, press any key to close the console.

### ✨ ප්‍රධාන පහසුකම් (Features)
- **User & System Temp ඉවත් කිරීම:** Apps සහ Windows මඟින් එකතු කර තබන අනවශ්‍ය Temporary Files ස්වයංක්‍රීයව ඉවත් කරයි.
- **Prefetch පිරිසිදු කිරීම:** කාලයක් තිස්සේ එකතු වූ අනවශ්‍ය Prefetch data මකා දමයි.
- **Windows Update Cache Cleanup:** Update වීමෙන් පසු System එකේ ඉතිරි වන විශාල Update installation files ඉවත් කර Storage එක නිදහස් කරයි.

- **Crash Dumps & Logs:** Error වලදී නිර්මාණය වන අනවශ්‍ය Logs සහ Dump files ඉවත් කරයි.
- **Recycle Bin එකවර පිරිසිදු කිරීම:** සියලුම Drives වල ඇති Recycle Bin එකවර Empty කරයි.
- **100% ආරක්ෂිතයි:** දැනට ක්‍රියාකාරී (Active) System files වලට කිසිදු හානියක් සිදු නොවේ.
